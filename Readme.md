# 🧠 EdgeBlock: Decentralized Edge Computing Resource Marketplace

## 📄 Project Description
**EdgeBlock** is a blockchain-based marketplace that connects **edge computing resource providers** (like individuals or companies with spare computing power) with **users** who need computational resources for AI, IoT, or data processing tasks.  
By leveraging **Ethereum smart contracts**, this system ensures **transparent transactions, trustless payments, and verified availability** of computing resources.

---

## 🌍 Project Vision
To create a **trustless, transparent, and efficient** marketplace that democratizes access to computing power—enabling individuals and organizations to **buy, sell, or rent** edge computing resources securely using blockchain technology.

---

## ✨ Key Features
- **Resource Listing:** Providers can register computing resources with details and hourly pricing.  
- **Decentralized Renting:** Users can rent resources and make secure payments directly via smart contracts.  
- **Transparency & Trust:** All transactions are recorded on-chain, ensuring accountability.  
- **Dynamic Availability:** Providers can update the status of their resources anytime.  

---

## 🚀 Future Scope
- Integrate **AI-based matching** between demand and available resources.  
- Add **reputation scoring** for providers and renters.  
- Enable **cross-chain interoperability** for multi-network support.  
- Build a **decentralized front-end (DApp)** using React and Web3.js.  
- Implement **token-based incentives** for frequent participants.  

---

## 🧱 Smart Contract
- **Language:** Solidity (v0.8+)  
- **Network:** Ethereum / Polygon / Any EVM-compatible chain  
- **Core Functions:**  
  1. `listResource()` – For providers to list their resources  
  2. `rentResource()` – For users to rent and pay for usage  
  3. `changeResourceStatus()` – To update availability
